## ⚡ The Problem: "The Production Break Anxiety"
Every developer, engineering lead, and DevOps team faces the same terrifying reality:
> *"I changed one function signature or database column on line 42... why did checkout, mobile notifications, and billing all crash in production?"*

Modern architectures are distributed webs of microservices, third-party adapters, database schemas, and background workers. Traditional linters and IDEs only analyze local file syntax—they have **zero visibility into cross-system ripple effects, contract breaches, or downstream blast radius.**

---

## 💡 The Solution: BlastRadius AI + Codebenders ACE
**BlastRadius AI** is an intelligent, visual architecture and code change simulation platform aligned with Codebenders' mission of **zero-downtime brownfield modernization and ambient software engineering**.

### 🌟 Key Capabilities:
1. **3D Holographic Animated Matrix UI**: Interactive Three.js WebGL visualizer rendering ambient microservice clusters, particle force fields, and dynamic blast pulse waves.
2. **Explore Live Architecture Topology**: Interactive, zoomable graph with service health, lines of code, test coverage, and dependency flows.
3. **Simulate Blast Radius in Real-Time**: Select any component and describe a proposed code modification. The system computes 1st-hop direct impacts and 2nd-hop ripple risks.
4. **Automated Breaking Change Detection**: Identifies API contract breaks, schema desyncs, and runtime exceptions before they happen.
5. **Auto-Generated Regression Tests**: Instantly writes TypeScript / Jest regression suites tailored to the exact blast radius.
6. **Interactive PR Mitigation Checklist**: Step-by-step pre-flight checklist to guarantee zero-downtime deployments.
7. **Codebenders Nexen AI Copilot**: Conversational AI assistant that understands your full system topology and ambient codebase dependencies.
8. **Custom Code Ingestion**: Upload custom project files (.ts, .js, .py) or paste source code; our AST parser constructs the graph automatically.

## 🛠️ Architecture & Tech Stack
* **Frontend**: React 19, TypeScript, Tailwind CSS v4, Framer Motion
* **3D Animated Engine**: **Three.js WebGL** (Geodesic Core, Torus Data Rings & 1,800 Holographic Particle Nodes)
* **Graph Engine**: `@xyflow/react` (React Flow) with custom interactive nodes and neon pulse shaders
* **AI Engine**: Dual-Mode Architecture:
  * **Codebenders Nexen AI & Gemini 2.0 Flash**: Deep semantic reasoning, contract verification, and test generation
  * **High-Precision Local AST Heuristics Engine**: Fallback zero-latency offline analyzer (100% demo uptime guaranteed)
* **Cloud Deployment**: **Render** Native Blueprint (`render.yaml`)
